2. Using walls to trigger turns: Nov 26, 2026

There are many ways to get from the start to our goal trophy! Below is a simple program that uses the while loop to drive forward until the proximity sensors see a wall. Whether to turn left or right is read from a list until the robot reaches the goal. You indicate the robot's name so that the program can compensate for known imbalances between left and right wheel motors.
from botcore import *
from time import sleep
from dpHelperCode import *

bot='Steve'
turnList=['LEFT','LEFT','RIGHT','RIGHT','FIN']
numTurns=len(turnList)

motors.enable(True)

nextTurn=True
turnCount=0
while turnCount<numTurns:

    driveToWall(bot)

    thisTurn=turnList[turnCount]
    if thisTurn=='RIGHT':
        turnRight()
    elif thisTurn=='LEFT':
        turnLeft()
    
    turnCount=turnCount+1


motors.enable(False)    #disable motors

1. Learn Looping, proximity checking, and condition testing: Oct 22, 2026

Below is a simple program that uses a while loop so the robot can appear to be alive. The proximity sensors are used to see walls in front, and the if structure is used to test whether a wall is close and stop the robot. The two front facing "proximity sensors" are like headlights.
from botcore import *
from time import sleep

motors.enable(True)

keepGoing=True
while keepGoing:

    #detect barrier
    p=prox.detect(1,5) #power 1to8, sens 0 to 100
    leds.prox(p) #turn on headlamps to show detection
    if any(p): #proximity detection
        motors.run(LEFT, 0)
        motors.run(RIGHT, 0)
    else:
        motors.run(LEFT, 40)
        motors.run(RIGHT, 40)

motors.enable(False)    #disable motors
